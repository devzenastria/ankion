# PROJECT_STATUS.md

## Public Summary

ankion is under active development as a privacy-first, voice-first mobile social discovery product.

The repository contains public-safe project documentation, mobile application groundwork, and architecture summaries. Detailed operational security procedures and implementation sequencing are maintained outside the public repository.

## Current Public Status

- Product direction is defined at a high level.
- Mobile app foundation work is progressing.
- Backend, account, privacy, and safety work are planned and reviewed through private internal gates.
- Public documentation is intentionally limited to non-sensitive summaries.

## Public-Safe Principles

- Users start with privacy by default.
- Real profile visibility requires explicit permission and server-side checks.
- Client state is not an authority for identity, visibility, payments, or access.
- Sensitive credentials are not stored in public documentation.
- Detailed security test matrices, operational procedures, and internal implementation plans are not published.

## Non-Goals For Public Status

This file does not publish internal task history, gate results, commit planning, security test procedures, database internals, deployment procedures, or detailed attack-surface notes.

## Security Note

If a public document appears to expose credentials or operational security details, treat it as a documentation security issue and sanitize it before any commit or push.
