# Database Schema Direction

## Public Summary

ankion expects a backend data model that supports privacy-first social discovery, profile visibility controls, media safety, and server-side access decisions.

## Public-Safe Principles

- Sensitive data access must be enforced by backend rules.
- Public documentation should not expose detailed internal schema design.
- Client applications should consume safe responses rather than raw sensitive records.

## Non-Goals / Omitted Internal Details

Detailed table definitions, internal relationships, access rules, and migration sequencing are maintained privately.

## Current Public Status

This document is a public-safe database direction summary.

## Security Note

Do not publish detailed schema internals or operational database procedures in this file.
