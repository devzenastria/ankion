# Technology Stack Direction

## Public Summary

ankion is planned as a TypeScript-based mobile-first product with supporting web and backend capabilities.

## Public-Safe Principles

- Mobile experience is the primary product surface.
- Backend services enforce sensitive access decisions.
- Public docs describe high-level technology direction only.
- Credentials and private operational procedures are not published.

## Current Public Direction

- TypeScript for application and shared code.
- Mobile-first app development.
- Web support for controlled public-safe surfaces.
- Backend services for accounts, data, and media access.
- Server-side checks for sensitive actions.

## Non-Goals / Omitted Internal Details

Detailed setup sequencing, private review steps, internal commands, and operation procedures are maintained outside the public repository.
