# Core Product Security Contract

## Public Summary

ankion is designed around privacy-first social discovery. Real identity visibility and sensitive access decisions must be controlled by server-side checks.

## Public-Safe Principles

- Privacy is the default state.
- Client state is not authoritative.
- Sensitive access decisions require server-side validation.
- Credentials and private environment values are not stored in public docs.

## Non-Goals / Omitted Internal Details

Detailed security contracts, internal checklists, test matrices, and implementation sequencing are maintained outside the public repository.

## Current Public Status

The public repository records high-level safety principles only.

## Security Note

Do not add operational security procedures, private identifiers, or credential material to this file.
