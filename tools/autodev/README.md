# AUTODEV

This directory contains local development helper tooling for the ankion project.

## Public Summary

The tooling is intended to support local, human-reviewed development workflows. It is not a production service and does not replace human review.

## Public-Safe Principles

- Human approval is required for meaningful changes.
- Tooling must not publish credentials or private operational details.
- Public documentation for tooling should stay high level.

## Omitted Internal Details

Detailed local procedures, internal reports, task queues, and review workflows are maintained privately and are not documented in the public repository.
